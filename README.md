# Digital Business Card

Simple one-page digital business card with:

- Profile image header.
- Tap-to-call and tap-to-email actions.
- **Save Contact** button that downloads a `.vcf` vCard file to import into phone contacts.
- Two sample website links.
- QR code that points to the current page URL.

## Run locally

Open `index.html` directly, or run any static server.

## Profile image

Place your real photo at `assets/profile.jpg`.
If it does not exist, the page automatically uses `assets/profile-placeholder.svg`.
